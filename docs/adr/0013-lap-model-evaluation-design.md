# ADR 0013: Evaluate lap-time forecasts with a calibration window, not per-stint in-sample baselines

- Status: accepted (refines the evaluation sketched in docs/ML-PLAN.md)
- Date: 2026-11-11

## Context
ML-PLAN.md defines baselines B0 (per-driver per-stint median) and B1 (per-driver per-stint linear
degradation) and a leave-one-race-out model. Taken literally, both baselines are fitted on the very
stint being scored (they see the answer) while the model never sees the held-out race, so the model
would lose by construction. In 2024 each circuit also appears once, so a leave-one-race-out model
cannot learn the pace level of the circuit it is tested on.

## Options considered
1. Literal plan: baselines fitted per scored stint. Unfair to the model; a win or loss would mean little.
2. Cold start: no information from the held-out race. The model cannot know circuit pace, so every
   method has errors of many seconds and the comparison says nothing about degradation or fuel.
3. Calibration window: every method may use each driver's first 5 clean laps of the held-out race and
   must predict the later clean laps. Same information for all methods; the model's only extra is
   what it learned from the other races.

## Decision
Option 3. B0 is persistence of the calibration median. B1 is a linear model (compound offsets,
per-compound tyre-age slope, one lap-number slope) fitted on the training races. LightGBM predicts the
same relative target. The calibration window (5 laps), minimum laps per driver (8), LightGBM
hyperparameters and bootstrap settings were fixed before any result was seen; no hyperparameter search
was run. Uncertainty comes from bootstrapping over races, including paired differences between methods.

## Consequences
The results answer "given a driver's early pace, can a cross-race model forecast later laps better than
simple baselines?", not "can the model predict absolute lap times". It is a different, narrower claim
than the plan's wording and must be described as such. Races are not independent draws; one season only.

## Evidence
`docs/ML-RESULTS.md`, generated by one logged run (MLflow experiment `f1-lap-time`).
